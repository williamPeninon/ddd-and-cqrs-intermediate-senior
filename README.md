# ddd-and-cqrs-intermediate-senior
Exercice technique réalisé en PHP 8 sans framework mettant en œuvre les principes DDD, CQRS, Clean Architecture et SOLID. Le projet met l'accent sur la modélisation métier, la séparation des responsabilités, la testabilité et la maintenabilité du code à travers une architecture robuste et évolutive.
